# ながれよみ

文章を短い「意味のまとまり」ごとに、画面の同じ場所へ次々と表示するAndroidの文章リーダーです。
視線をほとんど動かさずに、大学の授業資料・PDF・技術文書などの長い文章を読み進められます。

```
電磁波は → 電場と磁場が → 相互に変化しながら → 空間を伝わる現象である。
```

## 使い方

1. **読み込む**: 一覧画面の「貼り付け」「PDF・ファイル」「画像から」「撮影して」「入力」から。ほかのアプリで文字を選んで「ながれよみで読む」、または共有メニューからも読めます。
2. **流す**: 再生ボタン、または画面中央のタップで開始・一時停止。
   - 止めると、下に前後の文が出ます。タップするとその位置へ移動します。
   - ⏮ でいまの文の先頭（もう一度押すと前の文）、‹ › で1つずつ移動します。
3. **本文で確認**: 上の「本文」に切り替えると、普通の文章として読めます（いまの文がハイライト）。読みたい文をタップして「ここから流す」で続きに戻ります。
4. 数式やコードの行では自動で止まり、全体を表示します。「続きを流す」で再開します。

速さ（字/分）は画面下のボタンで、まとまりの長さ・文字の大きさは右上の設定で変えられます。読んでいた位置は資料ごとに保存されます。

## ビルド・テスト

```bash
./gradlew testDebugUnitTest          # ユニットテスト（区切り方・文分割・PDF整形・表示時間など）
./gradlew assembleDebug              # デバッグAPK
./gradlew connectedDebugAndroidTest  # エミュレータ/実機でのUIテスト
```

`app/build.gradle.kts` の `versionName` を上げて `main` に反映すると、CI成功後に自動でAPKが [Releases](https://github.com/orihami/nagareyomi/releases) に公開されます。開発ルールは [`CLAUDE.md`](./CLAUDE.md)、現在の状態は [`HANDOFF.md`](./HANDOFF.md) を参照してください。
